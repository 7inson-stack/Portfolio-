# Portfolio

A high-performance portfolio website replicated from [Daniele Buser](https://www.danielebuser.com/) — Creative Developer portfolio, built with Next.js App Router, Tailwind CSS v4, Framer Motion, and Three.js WebGL.

## Features

- **Selected Works / Projects**: Dynamic showcase cards with mouse tilt parallax and video preview popups.
- **Project Deep Dives**:
  - **Leonardo Berselli's Portfolio**: Interactive telemetry, hardware detector, button counter, and 3D WebGL ASCII particle globe.
  - **Ignition Finance**: Interactive asset allocation card, ETF metrics, and Play Store showcase preview.
- **About**: Sticky layered parallax layout, interactive 4-phase "How I Work" (Obsess, Design, Code, Ship) video showcase, and tech stack categorization.
- **Contacts**: Minimalist dark contact view with smooth entrance transitions.
- **Fluid Typography**: Responsive typography scale utilizing CSS `clamp()` and custom Tailwind utilities.
- **Custom Cursor & Smooth Scroll**: Lenis smooth scrolling with an interactive cursor tracking system.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion & Lucide Icons
- **3D Graphics**: Three.js WebGL
- **Smooth Scroll**: Lenis

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm run start
```
